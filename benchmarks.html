02 / EFFORT CURVES

low · medium · high · xhigh · max

effort를 올리면 얼마나 달라질까.

mid는 medium으로 표시합니다. 같은 effort 이름이 같은 토큰 예산을 뜻하지는 않습니다. max는 xhigh와 별개인 원문의 설정입니다.

셀을 누르면 아래 직접 비교에 적용됩니다. 점수 아래 금액은 해당 평가의 API 작업당 비용(USD)입니다. ‘미공개’는 0점이 아닙니다. fallback의 구성과 비용 산정은 각 원문을 따릅니다.

04 / CONDITIONS MATTER

실제 선택에 필요한 조건.

01 / HARNESS

모델과 제품을 구분

AA는 모델 API를 공통 평가 하네스로 실행합니다. 실제 Codex·Claude Code의 도구, 환경, 시스템 프롬프트까지 비교한 결과는 아닙니다.

02 / COST

점수와 비용을 함께

작업당 비용은 토큰 단가에 실제 사용량이 반영된 공개 수치입니다. 구독료·사용 한도와 다릅니다. 높은 effort의 추가 비용과 점수 증가를 함께 보세요.

03 / FALLBACK
