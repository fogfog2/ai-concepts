# AI Concepts

AI 개념을 **모델이 만들어져 서비스되기까지의 순서**로 정리한 기술 문서 모음입니다.

👉 **[사이트 보기](https://fogfog2.github.io/ai-concepts/)**

---

## 분류

문서를 주제가 아니라 파이프라인 단계로 묶었습니다.
한 문서가 정확히 한 단계에 속하므로 겹침이 없고, 순서 자체가 읽는 순서가 됩니다.

| 단계 | 성격 |
|---|---|
| 01 기초 | 모든 모델의 밑바닥 부품 — 토큰화, 임베딩, 정규화, 역전파 |
| 02 아키텍처 | 무엇을 쌓을 것인가 — Transformer, ViT, MoE, RNN/LSTM |
| 03 학습 | 어떤 과제로 가르칠 것인가 — BERT, Diffusion, CLIP, Scaling Laws |
| 04 적응·정렬 | 학습된 모델을 길들이기 — LoRA, RLHF |
| 05 추론 최적화 | 같은 모델을 싸고 빠르게 — FlashAttention, KV Cache, 양자화 |
| 06 응용·시스템 | 실제로 쓰이는 형태 — RAG, MCP |
| 07 특집 · 객체 검출 | 검출기 계보를 순서대로 — R-CNN에서 RF-DETR까지 |

위에서부터 읽으면 하나의 흐름이 되고, 필요한 단계만 골라 봐도 됩니다.

## 작성 기준

- 컴퓨터·AI 전공 수준을 기준으로 작성했습니다.
- 수치는 가능한 한 **직접 계산해 검증한 것**만 실었습니다.
- 최신 주제는 **1차 출처를 확인한 뒤** 작성했고, 각 문서 끝에 문헌을 남겼습니다.
- 벤치마크 수치는 측정 조건(하드웨어·정밀도·해상도)을 함께 적었습니다.

## 구조

정적 사이트입니다. 빌드 도구도 외부 CDN 의존성도 없습니다.

```
index.html      진입 페이지
style.css
ai.js           단계별 렌더링
data/
  artifacts.json  문서 목록 (제목·링크·단계)
  index.json      뉴스 날짜 목록
```

문서 본문은 별도 페이지로 호스팅되며, 이 저장소에는 목록과 링크만 있습니다.
