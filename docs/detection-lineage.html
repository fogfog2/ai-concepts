Object Detection 계보

2단계에서 1단계로 — 검출기가 무엇을 하나씩 버려 왔는가

검출이 어려운 이유는 출력 개수가 입력마다 다르다는 데 있다. 신경망은 고정 크기 출력을 내놓는데, 객체는 0개일 수도 50개일 수도 있다. 검출기 10년의 역사는 이 하나의 질문에 대한 답의 변천이고, 동시에 보조 장치를 하나씩 떼어내는 과정이다 — 제안 단계, 앵커, 그리고 NMS.

01분류와 검출은 다른 문제다

이미지 분류는 "이 사진에 무엇이 있는가"에 답한다. 출력이 하나다. 검출은 "무엇이 어디에 몇 개 있는가"에 답해야 한다. 출력 개수가 입력마다 다르다 — 이것이 문제를 근본적으로 어렵게 만든다.

신경망은 고정 크기 출력을 내놓는다. 객체가 0개일 수도 50개일 수도 있는 문제를 어떻게 고정 크기 출력에 담을 것인가. 검출기 20년 역사의 상당 부분이 이 하나의 질문에 대한 서로 다른 답이다.

가장 직관적인 답은 후보를 잔뜩 만들고 각각을 분류하는 것이다. "여기에 객체가 있나?"를 수천 번 물으면, 가변 개수 문제가 고정 개수 분류 문제로 바뀐다. 2단계 검출기가 이 길을 갔다.

022단계 — 후보를 먼저 고르고, 그다음 판단한다

R-CNN(2014)의 절차는 단순하다. 선택적 탐색(selective search)이라는 고전 알고리즘으로 객체가 있을 법한 영역 약 2000개를 뽑고, 각 영역을 잘라내 CNN에 넣어 분류한다. 정확도는 당시 기준으로 압도적이었다. 문제는 속도였다.

이미지 한 장에 CNN을 2000번 돌린다. 영역들이 서로 크게 겹치는데도 겹친 부분의 특징을 매번 다시 계산한다. 이미지 한 장 처리에 수십 초가 걸렸다.

모델바꾼 것CNN 호출영역 제안
R-CNN (2014)—~2000회외부 알고리즘
Fast R-CNN (2015)RoI 풀링1회외부 알고리즘
Faster R-CNN (2015)RPN1회신경망 내부

Fast R-CNN은 CNN을 이미지 전체에 한 번만 돌리고, 특징 맵에서 각 영역에 해당하는 부분을 잘라내 쓴다(RoI 풀링). 중복 계산이 사라졌다. Faster R-CNN은 마지막 외부 의존이던 영역 제안까지 신경망(RPN)으로 흡수했다. 이제 검출 전체가 하나의 학습 가능한 신경망이 됐다.

그럼에도 구조는 여전히 2단계다. 제안을 만들고, 각 제안을 판단한다. 실시간(30 FPS)에는 미치지 못했다.

031단계 — 격자에 직접 예측하기

YOLO(2015)의 발상은 후보 선별 단계를 아예 없애는 것이었다. 이미지를 격자로 나누고, 각 칸이 직접 "내 칸에 객체 중심이 있는가, 있다면 어떤 박스인가"를 한 번에 예측한다. 이름 그대로 이미지를 한 번만 본다.

1단계 검출의 출력 — 고정 크기 텐서 하나
출력 = S × S × (B × 5 + C)
// S×S 격자, 칸마다 B개 박스(x,y,w,h,신뢰도) + C개 클래스 확률

가변 개수 문제가 이렇게 풀린다. 출력은 항상 고정 크기이고, 신뢰도가 낮은 칸을 버리는 것으로 개수를 조절한다. 속도는 극적으로 빨라져 처음으로 실시간 검출이 가능해졌다.

041단계가 정확도를 잃던 이유

초기 YOLO는 빨랐지만 2단계보다 정확도가 낮았다. 특히 작은 객체와 밀집한 객체에 약했다. 원인 중 하나는 극단적인 클래스 불균형이다.

2단계 검출기는 제안 단계에서 이미 후보를 걸러낸다. 분류기가 보는 것은 "그럴듯한" 영역 수백 개다. 반면 1단계는 격자의 모든 위치를 판단해야 하고, 그중 실제 객체는 극소수다.

불균형의 규모
후보 100,000개 중 실제 객체 20개 → 배경이 99.98%
배경 : 객체 = 4,999 : 1

배경이 압도적으로 많으면 학습이 망가진다. 개별 배경 예제는 쉽지만(신뢰도 0.99로 맞힘), 개수가 워낙 많아 손실 총합을 지배한다. 모델은 "전부 배경"이라고 답하는 쪽으로 끌려간다.

RetinaNet(2017)의 Focal Loss가 이것을 정면으로 풀었다. 교차 엔트로피에 (1−p)γ를 곱해 이미 잘 맞히는 예제의 손실을 억제한다.

예측 확률 pγ=0 (일반 CE)γ=2 (Focal)억제 배율
0.9 (쉬운 배경)1.00000.0100100배 감소
0.99 (매우 쉬움)1.00000.000110,000배 감소
손실 함수 하나가 구조 차이를 지웠다. Focal Loss 이후 1단계 검출기는 2단계와 대등한 정확도에 도달했고, 속도 우위는 그대로였다. 이 시점부터 2단계는 사실상 밀려났다. 검출기의 성능을 가른 것이 백본도 해상도도 아닌 라벨과 손실을 다루는 방식이었다는 관찰은 이후 YOLOX의 SimOTA에서 다시 반복된다. 같은 시기에 박스 쪽에서도 나란히 진행된 일이 있다 — 좌표 L1 을 IoU 계열 손실로 갈아 끼워 학습 손실과 평가 지표를 같은 함수로 만드는 작업이다.

05남은 두 개의 목발 — 앵커와 NMS

1단계가 자리를 잡은 뒤에도 두 가지 보조 장치가 남았다. 둘 다 "가변 개수 출력"이라는 원래 문제를 우회하려고 도입된 것이고, 이후 발전의 주된 표적이 된다.

  • 앵커 박스. 격자 칸마다 미리 정한 크기·비율의 기준 박스를 두고, 그 기준에서 얼마나 벗어나는지를 예측한다. 학습이 쉬워지지만 데이터셋마다 앵커를 다시 정해야 하고, 하이퍼파라미터가 늘어난다. YOLOX가 이것을 걷어낸다(앵커 프리).
  • NMS(비최대 억제). 같은 객체를 이웃한 여러 칸이 동시에 예측하므로, 겹치는 박스 중 신뢰도가 높은 것만 남기고 지운다. 학습되지 않는 후처리이고, 밀집한 객체에서 진짜 박스를 지우는 실수를 한다. 임계값도 손으로 정해야 한다.

정리하면 검출기의 계보는 세 번의 제거로 읽을 수 있다. 2단계는 제안 단계를 제거해 1단계가 됐고, YOLOX 계열은 앵커를 제거했으며, 마지막 남은 NMS를 제거하는 것이 DETR 계열과 최신 YOLO(v10, YOLO26)의 과제였다.

다음 편에서는 YOLO 계열이 v5부터 최신까지 이 목발들을 어떻게 하나씩 떼어냈는지, 그다음 편에서는 아예 다른 각도에서 출발해 처음부터 NMS가 없던 DETR 계보를 다룬다.
